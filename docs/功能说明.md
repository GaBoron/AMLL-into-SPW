# 功能说明

[← 返回 README](../README.md)

AMLL into SPW 在 SPW 播放页面显示动态歌词。进入播放界面即可使用；歌词内容取决于当前歌曲及其歌词来源。

## 歌词显示与操作

插件支持逐字高亮、整行高亮、对唱、背景人声、翻译、音译和注音。歌词只有逐行时间轴时按整行高亮，不会生成逐字时间。

- 点击或轻触歌词行可跳转播放；上下拖动、滚轮、方向键和 Page Up / Page Down 可浏览歌词。
- 停止手动浏览约三秒后恢复自动跟随；双击歌词区域或按 Home、Esc 可立即恢复。
- 鼠标或触控笔悬停时显示歌词行框，约三秒无操作后淡出；触摸时也有行框反馈。
- 在歌词区域右键、使用笔的右键按钮，或用手指／笔尖长按，可打开菜单；鼠标按住左键也可长按。按住后开始拖动或增加触点会取消长按。

菜单可复制整首歌词原文，或按“原文、翻译”逐行复制；复制内容不包含时间标签、音译、注音或底栏信息。翻译被隐藏时仍可复制，无可用歌词或纯音乐时复制项不可用。

右键菜单沿用宿主样式；使用重构播放页时，菜单使用液态玻璃材质。菜单可切换翻译、音译与注音、底栏信息的显示；设置立即生效并保存，与插件设置中的对应选项共用。无歌词和纯音乐页面也可使用这些显示开关。

如需支持开发，可使用插件设置“支持开发”中的“爱发电赞助”入口，在默认浏览器中打开[赞助页面](https://afdian.com/a/gaboron)。

在插件设置的“歌词内容”中，可分别控制翻译，以及音译与注音，也可隐藏已唱过的歌词和底栏信息。已唱歌词在暂停或手动浏览时重新显示。

自动注音与对唱／背景歌词识别集中在“实验性功能”分组，默认关闭。

“显示翻译语种”默认中文（优先简体）。多语种 TTML 每行只显示所选语种的一条翻译，也可选择优先繁体或其他语种；同语种有多个地区版本时优先匹配。缺少所选语种时，仅回退到未标语种的翻译，否则不显示翻译。切换立即生效，“复制歌词原文及翻译”使用同一选择；原始 TTML 中的其他语种仍保留。

有歌词时，底栏默认显示歌词元数据和实际歌词来源；其他插件也可提供补充信息。开启“隐藏底栏信息”可将这些内容一起隐藏，无歌词和纯音乐页面的插件信息也会隐藏。

宿主 SPL / LRC 歌词可能将翻译和音译放在一起。插件会尝试识别其中的日语罗马音、韩语音译和带声调的中文拼音；开启粤语注音且歌曲语言标为粤语时，也会识别与原文匹配的粤拼。无法确定的内容保留为翻译。

## 重构播放页

在插件设置的「重构播放页」分组开启「启用重构播放页」，可使用按 AMLL Player 的 `react-full` 布局与控件样式移植的整页播放器。此设置默认关闭，仅作用于展开的播放页。曲库、设置与底部迷你播放条继续使用宿主样式。窗口宽于高时，左侧显示封面、曲目信息、播放控制与音量，右侧显示歌词。窗口高于宽时，歌词模式使用小封面与曲目信息。开启「彩色歌词」后，左侧控件使用相同配色。

同一分组中的「沉浸式封面」默认关闭。开启后，封面在原位置保留主体和细节，边缘接入从原图提取的底色和纹理。平滑封面的背景保留少量纹理，封面本身有明显颗粒时延续其质感。歌词和控件按各自区域的背景选色，时间与音量气泡按气泡自身的底色选取文字颜色。暂停时封面保持原位，切歌时封面和配色同步更新。关闭此选项或遇到无封面曲目时，播放页使用常规背景。

点击封面可显示或隐藏歌词。竖屏隐藏歌词后显示大封面与完整控制区。常规封面在切歌时从两侧交替移入、移出，暂停时缩小并露出黑胶唱片。「减少动态效果」会停止背景流动并关闭这些过渡动画。

底部音量条显示本地曲目的真实频谱：柱高随音乐变化，独立于宿主音量，静音时也继续分析；亮暗分界表示音量，仍可拖动调节。低频与高频分别分析以保留低音轮廓和短促鼓点，无法解码的文件不显示动态频谱。切歌、暂停或音频数据暂时中断时，频谱平滑收敛。进度条和音量频谱拖动时显示当前时间或百分比，松手后保持提交的位置，等待播放器确认。

播放控制左侧的模式按钮依次切换顺序播放、列表循环、单曲循环和随机播放，右侧按钮打开播放列表。曲目信息旁的三点按钮保留 SPW 原有“更多”操作，包括 SPW Lyrics 接入的歌词工具。更多与播放列表使用液态玻璃材质，并在打开、关闭时平滑过渡。歌词操作、右键菜单、翻译、注音和纯音乐诗词继续可用，顶部保留 SPW 的原生收起手柄。

播放 SPW 曲库中的歌曲时，曲目信息旁的三点菜单顶部会显示「转到歌手页」和「转到专辑」。有多位歌手时，从展开的二级菜单选择要查看的歌手。点击二级菜单顶部可以返回。选择目标后会收起播放页并打开对应的 SPW 曲库页面。菜单只显示有对应曲目信息的入口。

同时启用支持联动的 SPW Track Mix 时，右下角的推子图标会打开六轨调音台。可在弹层中选择标准分离或快速分离，切歌后仍会按原曲名显示后台任务进度。调音台右上角的齿轮可查看模型状态或进入「管理缓存」，按歌查看占用和删除缓存。分离完成后可调节各轨音量、静音或独奏。音量条的频谱随六轨混音变化，切回原曲后显示原曲频谱。

外部音源的播放操作交给当前音源插件；不提供播放控制接口的音源会禁用播放按钮，需在音源插件中操作。播放模式、播放列表与真实频谱仅用于宿主本地播放；外部音源的音量条保留调节功能，频谱保持静止。关闭「启用重构播放页」即可恢复原版播放页。宿主整页入口不可用时，继续使用原版页面及 AMLL 歌词。

## 自动识别对唱与背景歌词

“自动识别对唱与背景歌词”默认关闭。开启后，行首的“男：”“女：”、歌手姓名等冒号标记用于切换角色，也支持角色名单独占一行。未标注的后续歌词继承当前角色，直到遇到新的标记；重复标记保持同一角色。“合：”“合唱：”“全体：”等切回合唱。角色按首次出现的顺序交替安排在左右两侧，角色标记不作为歌词显示。

圆括号或全角圆括号中的歌词可显示为背景人声，包括整行括号歌词和主歌词内的括号片段。已有 TTML 声部标记、逐字注音及音译时间轴优先保留；无法安全拆分的内容保持原样。此功能不修改歌词文件或原始 TTML，也不推算新的逐字时间。普通冒号说明和非演唱用途的括号文字仍可能误判，可关闭此选项恢复原有显示。

## 字体与颜色

在插件设置的“字体与颜色”中，可以调整字号、字重和歌词颜色。字号默认随窗口宽度自动调整，也可从 18–72 的预设中选择。开启“彩色歌词”后，歌词从封面取色。使用沉浸式封面时，彩色歌词会按背景调整明度和饱和度，关闭彩色歌词时自动选择黑色或白色。

默认字体为内置思源黑体 SC，默认字重为中等。点击“选择歌词字体文件…”可选择 TTF、OTF、TTC 或 OTC 文件；Windows 默认打开当前用户的 `%LOCALAPPDATA%\Microsoft\Windows\Fonts` 文件夹，无法使用时打开系统字体文件夹。自定义字体应用于歌词、翻译、音译、注音、纯音乐标题和底栏；诗词正文使用独立字体。

自定义字体会按文件实际支持的样式匹配字重，缺少的字符回退到系统字体。取消选择或选择无效文件时保留原设置；字体文件移动或卸载后，插件会提示并回退到内置字体。点击“恢复内置歌词字体”可恢复默认字体，保留字号和字重。

## 动态效果

“动态效果”中可分别调整非活动歌词模糊、歌词缩放与逐字浮动和长音发光。“弹簧滚动与错落动画”同时控制滚动、错落移动，以及翻译、音译和底栏的弹簧展开与收起。开启“减少动态效果”会关闭这些效果，保留歌词高亮。

## 纯音乐与诗词

没有可用歌词或歌词仅包含纯音乐提示时，页面默认显示“纯音乐 / INSTRUMENTAL”和离线诗词。双击诗词，或将焦点移到诗词区域后按 Enter / 空格，可换一首；长篇可滚动阅读。

开启“隐藏纯音乐诗词”后，诗词隐藏，纯音乐标题放大并居中。其他插件的底栏信息仍可显示，由“隐藏底栏信息”独立控制。

## 实验性日语注音

“自动生成逐字罗马注音”默认关闭，需同时开启“显示音译与注音”。它只处理识别为日语的歌词：优先保留已有逐字音译或注音，将已有整行音译尽量对齐原文；没有音译时使用内置词典离线生成。

人名、特殊读法和变读可能不准确。此功能不修改歌词文件，关闭后恢复原有内容。

## 实验性韩语注音

“自动生成逐字韩语注音”默认关闭，需同时开启“显示音译与注音”。插件按韩文音节离线生成逐字罗马注音，无需填写歌曲语言。支持现代韩文及其分解字母形式，混合歌词只为韩文部分生成注音。

已有逐字注音和音译时间轴优先保留；已有整行罗马音会尝试对齐，无法完整匹配时回退到自动生成的逐字注音。成功生成后优先显示逐字注音，不重复显示整行罗马音。生成规则参考[韩国国立国语院的罗马字表记规则](https://www.korean.go.kr/front_eng/roman/roman_01.do)，处理相邻韩文音节间常见的连音、鼻音化、流音化、腭化及与 ㅎ 相关的音变，不推测跨空格的连读。

罗马字用于辅助跟唱，并非精确音标。独立字母、古韩文、汉字读音、依赖词素边界的音变、人名和特殊唱法可能无法生成或读音不准。此功能不修改歌词文件或原有逐字时间，关闭后恢复原有内容。

## 实验性粤语注音

“自动生成逐字粤语注音”默认关闭，需同时开启“显示音译与注音”。插件读取音频文件的“语言”元数据来识别粤语；可在 SPW Lyrics 的元数据编辑器中将该字段填写为 `粤语`、`粵語`、`Cantonese`、`yue` 或 `zh-yue`，也支持 `yue-Hant` 等语言标签。保存后，播放中的歌曲会自动重新识别。

音频语言未填写时，回退到 TTML 的语言元数据（如 `xml:lang="yue"`）。未标明粤语的歌曲不会生成粤拼，`中文`、`zh` 或 `zh-HK` 也不会被当作粤语。

识别后使用内置词典离线生成带 1–6 声调数字的逐字粤拼，支持简繁体并优先匹配词组读音。已有逐字注音和音译时间轴保持优先；已有整行粤拼会尝试对齐。遇到非标准拼写或无法完整对齐的整行音译时，改用词典生成逐字粤拼。成功生成后优先显示逐字注音，不重复显示原整行音译；无法生成时保留整行。混合歌词中的英文、标点、未知汉字及含日文假名或韩文的行不会被强行注音。

多音字、人名、变调和歌曲特殊唱法仍可能不准确。此功能只改变显示，不修改歌词文件或原有逐字时间；关闭后恢复原有内容。词典来源及许可证见 [第三方组件](../THIRD_PARTY_NOTICES.md)。

## 歌词来源与优先级

与支持来源同步的 SPW Lyrics 一起使用时，跟随其当前播放选择：选中 TTML 时保留对应原文；选中 LRC / SPL 时采用宿主歌词。本地另一份 TTML 不会覆盖该选择；写入歌曲后使用保存后的歌词内容。

未收到播放来源选择时，按以下顺序选择可用歌词：

1. 与歌曲同名的 `.ttml` 文件。
2. 音频标签中的原始 TTML。
3. 与歌曲同名的 `.lrc` 文件中的 TTML 内容。
4. 其他插件提交的原始 TTML。
5. SPW 已解析的 SPL / LRC 歌词。

普通 TTML 提交仍遵循上述本地优先级；显式来源同步见[接口说明](TTML互通.md)。启用顺序不限，AMLL into SPW 不修改音频或歌词文件。

其他插件可通过 [原始 TTML 接口](TTML互通.md)提供歌词，通过[底部信息栏接口](底部信息栏接口.md)提供补充信息。
