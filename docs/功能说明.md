# 功能说明

[← 返回 README](../README.md)

AMLL into SPW 在 SPW 播放页面显示动态歌词。进入播放界面即可使用；歌词内容取决于当前歌曲及其歌词来源。

## 歌词显示与操作

插件支持逐字高亮、整行高亮、对唱、背景人声、翻译、音译和注音。歌词只有逐行时间轴时按整行高亮，不会生成逐字时间。

- 点击歌词行可跳转播放；滚轮、方向键和 Page Up / Page Down 可浏览歌词。
- 停止手动浏览约三秒后恢复自动跟随；双击歌词区域或按 Home、Esc 可立即恢复。
- 鼠标悬停时显示歌词行框，约三秒无鼠标操作后淡出。

在插件设置的“歌词内容”中，可分别控制翻译，以及音译与注音，也可隐藏已唱过的歌词和底栏信息。已唱歌词在暂停或手动浏览时重新显示。

有歌词时，底栏默认显示歌词元数据和实际歌词来源；其他插件也可提供补充信息。开启“隐藏底栏信息”可将这些内容一起隐藏，无歌词和纯音乐页面的插件信息也会隐藏。

宿主 SPL / LRC 歌词可能将翻译和音译放在一起。插件会尝试识别其中的日语罗马音、韩语音译和带声调的中文拼音；开启粤语注音且歌曲语言标为粤语时，也会识别与原文匹配的粤拼。无法确定的内容保留为翻译。

## 字体与颜色

在插件设置的“字体与颜色”中，可以调整字号、字重和歌词颜色。字号默认随窗口宽度自动调整，也可从 18–72 的预设中选择。开启“彩色歌词”后，歌词使用封面的主色；没有封面时使用白色。

默认字体为内置思源黑体 SC，默认字重为中等。点击“选择歌词字体文件…”可选择 TTF、OTF、TTC 或 OTC 文件；Windows 默认打开当前用户的 `%LOCALAPPDATA%\Microsoft\Windows\Fonts` 文件夹，无法使用时打开系统字体文件夹。自定义字体应用于歌词、翻译、音译、注音、纯音乐标题和底栏；诗词正文使用独立字体。

自定义字体会按文件实际支持的样式匹配字重，缺少的字符回退到系统字体。取消选择或选择无效文件时保留原设置；字体文件移动或卸载后，插件会提示并回退到内置字体。点击“恢复内置歌词字体”可恢复默认字体，保留字号和字重。

## 动态效果

“动态效果”中可分别调整非活动歌词模糊、歌词缩放与逐字浮动、长音发光和弹簧滚动。开启“减少动态效果”会关闭这些效果，保留歌词高亮。

## 纯音乐与诗词

没有可用歌词或歌词仅包含纯音乐提示时，页面默认显示“纯音乐 / INSTRUMENTAL”和离线诗词。双击诗词，或将焦点移到诗词区域后按 Enter / 空格，可换一首；长篇可滚动阅读。

开启“隐藏纯音乐诗词”后，诗词隐藏，纯音乐标题放大并居中。其他插件的底栏信息仍可显示，由“隐藏底栏信息”独立控制。

## 实验性日语注音

“自动生成逐字罗马注音（实验性）”默认关闭，需同时开启“显示音译与注音”。它只处理识别为日语的歌词：优先保留已有逐字音译或注音，将已有整行音译尽量对齐原文；没有音译时使用内置词典离线生成。

人名、特殊读法和变读可能不准确。此功能不修改歌词文件，关闭后恢复原有内容。

## 实验性粤语注音

“自动生成逐字粤语注音（实验性）”默认关闭，需同时开启“显示音译与注音”。插件读取音频文件的“语言”元数据来识别粤语；可在 SPW Lyrics 的元数据编辑器中将该字段填写为 `粤语`、`粵語`、`Cantonese`、`yue` 或 `zh-yue`，也支持 `yue-Hant` 等语言标签。保存后，播放中的歌曲会自动重新识别。

音频语言未填写时，回退到 TTML 的语言元数据（如 `xml:lang="yue"`）。未标明粤语的歌曲不会生成粤拼，`中文`、`zh` 或 `zh-HK` 也不会被当作粤语。

识别后使用内置词典离线生成带 1–6 声调数字的逐字粤拼，支持简繁体并优先匹配词组读音。已有逐字注音和音译时间轴保持优先；已有整行粤拼会尝试对齐，无法完整匹配时保留原有内容，不用自动读音替换。混合歌词中的英文、标点、未知汉字及含日文假名或韩文的行不会被强行注音。

多音字、人名、变调和歌曲特殊唱法仍可能不准确。此功能只改变显示，不修改歌词文件或原有逐字时间；关闭后恢复原有内容。词典来源及许可证见 [第三方组件](../THIRD_PARTY_NOTICES.md)。

## 歌词来源与优先级

插件按以下顺序选择可用歌词：

1. 与歌曲同名的 `.ttml` 文件。
2. 音频标签中的原始 TTML。
3. 与歌曲同名的 `.lrc` 文件中的 TTML 内容。
4. 其他插件提交的原始 TTML。
5. SPW 已解析的 SPL / LRC 歌词。

本地 TTML 优先于其他插件提交的 TTML。[SPW Lyrics](https://github.com/GaBoron/SPW-Lyrics) 可向本插件提供原始 TTML；同时启用两个插件即可使用。AMLL into SPW 不修改音频或歌词文件。

其他插件可通过 [原始 TTML 接口](TTML互通.md)提供歌词，通过[底部信息栏接口](底部信息栏接口.md)提供补充信息。
