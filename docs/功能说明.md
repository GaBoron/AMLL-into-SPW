# 功能说明

[← 返回 README](../README.md)

AMLL into SPW 通过 SPW Workshop API 接入原生播放页面，使用 Compose / Skia 呈现参考 [Apple Music-like Lyrics（AMLL）](https://github.com/amll-dev/applemusic-like-lyrics) 的动态歌词。正常进入 SPW 播放界面即可使用，不会打开独立窗口，也不替换宿主播放控制。

## 歌词与声部

- **逐字与整行高亮**：支持逐字渐变高亮、浮动及长音发光；仅有行级时间轴时，整行高亮，不虚构逐字时间戳。
- **对唱与背景人声**：根据演唱者信息将歌词分布在左右两侧，双方在对侧留出间距，允许多个声部同时高亮。背景人声随所属歌词组进入时展开，保留完整尾音；未展开时不预留空行。
- **翻译与注音**：支持翻译、音译和 Ruby 注音。长句参考标点、空格及词界均衡换行，同时保留歌词本身的换行。

TTML 包含独立时间戳的逐字音译时，会将音译标在对应原文上方，随原词浮动并渐变高亮。

## 实验性日语注音

“自动生成逐字罗马注音（实验性）”默认关闭，仅处理识别为日语的歌词：

1. **已有逐字音译或 Ruby 注音**：保留已有内容，不覆盖。
2. **只有整行音译**：利用本地分词及读音匹配逐字位置，保留原有拼写。
3. **没有音译**：通过随包提供的 Kuromoji 词典离线生成读音。

汉字词组可按整词注音；只能部分匹配时，对齐可靠片段，其余音译均匀分布在对应原文上方，随原词浮动与高亮。整行无法匹配时，仍在原文上方保留整行音译。人名、特殊读法和变读可能无法准确识别。

分析在后台加载歌词时进行，并使用内存缓存；不修改歌词原文、高亮时间轴或磁盘文件。此功能适用于不同歌词来源，不依赖 SPW Lyrics。关闭实验性生成后恢复原有歌词；原本存在的逐字音译与注音仍受“显示音译与注音”选项控制。

## 动效与排版

- 弹簧滚动、错落位移、活动行缩放、非活动行模糊和视口边缘淡出。
- 连续密集换行时缩短过渡并平滑跟随，使高亮与声部显示同步；近同时声部或偶发短间隔仍使用普通弹簧，只有持续明显落后时才启用追赶。
- 前奏与长间奏显示三点提示，歌词区域与 SPW 整页背景透明衔接。
- 内置思源黑体 SC 可变字体，提供 ExtraLight、Light、Regular、Medium、Bold、Heavy 六种字重，默认中等 500，最粗 900；缺字回退系统字体。
- 主歌词字号可自动适应窗口，也可使用 18–72 的预设值；翻译、音译及注音按比例缩放。

## 歌词操作与元数据

- 普通歌词页面中，鼠标悬停显示歌词行框，点击歌词可跳转播放并平滑滚动。
- 支持滚轮、方向键和 Page Up / Page Down 手动浏览。停止操作约三秒后恢复自动跟随；在普通歌词页面双击、按 Home 或 Esc 可立即恢复跟随。
- 歌词末尾以较小、较淡的文字显示文件中的歌曲元数据和实际歌词来源，随歌词滚动，唱完后聚焦显示，也可手动滚动查看。
- 元数据支持多值和自定义字段。实际歌词来源由 AMLL 保留；原始 TTML 来自其他插件时显示为「跨插件 TTML」。
- 其他插件可通过 [底部信息栏接口](底部信息栏接口.md) 提交 key/value。AMLL 自身信息固定在前，其他分组按插件声明名称的中文拼音／英文字母顺序排列，每组末尾统一以更小、更淡的 `From: 名称` 显示来源。支持有歌词、无歌词与纯音乐页面。

## 纯音乐与诗词

歌词加载结束后，若当前歌词为空，或全部为“纯音乐”“Instrumental”等纯音乐提示，页面顶部会显示“纯音乐 / INSTRUMENTAL”，中央展示诗词。

诗词从离线内置的 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry) 选篇中随机抽取，覆盖《诗经》《楚辞》、汉魏诗、唐诗、五代词、宋词、元曲及清词，采用独立阅读排版，完整展示一首诗词。

播放同一首歌时保留当前选篇。双击诗词区域，或将焦点移到诗词区域后按 Enter / 空格，可换一首诗词；长篇可滚动阅读。切换诗词或恢复普通歌词时采用淡入淡出。

纯音乐页面隐藏 AMLL 自身的歌曲元数据与歌词来源信息栏，继续显示其他插件提交的信息。

## 可调整的设置

在 SPW 的插件设置中可以调整：

| 设置 | 行为 |
| --- | --- |
| 模糊、缩放、长音发光、弹簧动画 | 分别控制对应的显示效果 |
| 彩色歌词 | 使用封面的明亮主色，为歌词、翻译和间奏提示着色；默认关闭，没有封面时使用白色 |
| 隐藏已唱歌词 | 整组声部唱完后渐隐；暂停或手动浏览时重新显示 |
| 显示音译与注音 | 切换音译、注音的可见性 |
| 自动生成逐字罗马注音（实验性） | 默认关闭；按已有音译或本地词典为日语歌词补充注音，详见 [实验性日语注音](#实验性日语注音) |
| 减少动态效果 | 关闭模糊、发光、缩放和弹簧动画，保留准确高亮 |
| 字重与字号 | 选择内置字重，或使用自适应 / 预设字号 |

## 歌词来源与优先级

按以下顺序选择可用歌词：

1. 歌曲同名 `.ttml` 文件。
2. 音频标签内的原始 TTML。普通歌词标签不会阻止继续查找其他 TTML 标签。
3. 歌曲同名 `.lrc` 文件中的 TTML 内容。
4. 其他插件通过原始 TTML 接口提交的歌词。
5. SPW 已解析的 SPL / LRC 时间轴。

原始 TTML 直接解析并保留原文，不经过 SPL 转换。没有可用 TTML 时，插件使用 SPW 提供的歌词行、逐字单元和翻译，在内存中生成兼容 TTML。不改写音频、歌词文件或其他插件缓存，也不会为行级歌词编造逐字时间戳。

[SPW Lyrics](https://github.com/GaBoron/SPW-Lyrics) 已适配原始 TTML 互通接口，同时启用后即可传递完整歌词信息。其他歌词插件也可使用同一协议。

接口定义、时间偏移规则、调用模板与接入示例参见 [原始 TTML 接入指南](TTML互通.md)。

## 启用与停用

安装与授权步骤见 [README](../README.md)。

停用插件后恢复 SPW 原生歌词界面，同时关闭原始 TTML 与底部信息栏接口，并清空外部信息。
