# 重构播放页扩展 API

插件可向 AMLL 的重构播放页提供右下角入口、液态玻璃面板和频谱数据。使用同一 JVM 的平台 MBeanServer 注册扩展。数据只使用 Java 平台类型，因此插件可以各自打包并独立更新。

## 检测宿主

查询 `io.github.gaboron.amllspw:type=RebuiltPlayer,version=2`。`Active` 表示正在使用重构播放页，`PanelApiVersion` 和 `SpectrumApiVersion` 分别给出可用的协议版本。宿主停用后注销该端点。提供方也应在自身停用时注销各扩展端点。

## 面板扩展 v1

使用 `StandardMBean` 注册 `io.github.gaboron.amllspw:type=PlayerPanel,version=1,provider=<插件 ID>`。使用合法、唯一的插件 ID。身份由 ObjectName 决定。

```java
public interface PlayerPanel {
    Map<String, Object> getDescriptor();
    List<Map<String, Object>> render(String session, Map<String, String> context);
    void action(String session, Map<String, String> context, String action, int value);
    void close(String session);
}
```

`Descriptor` 中的 `label` 是入口的可访问名称，必填。`svg` 是内联单色 SVG，颜色由宿主主题着色。可选项包括 `width`（默认 320 dp，范围 240–640）、`order`（按升序显示，默认 0），以及 `keepOnTrackChange`（切歌时保留弹层，默认关闭）。

宿主在每次打开弹层时分配新的 `session`，在关闭时调用 `close`。`context` 包含当前本地曲目的 `trackId` 和 `path`，无本地曲目时为空字符串。提供方可以按 `session` 管理当前页面和设置草稿。宿主会在弹层可见时定期调用 `render`，并在操作后立即刷新。请在这些方法中读取已有状态或提交后台工作，避免阻塞界面。

`render` 按显示顺序返回控件列表。每项需包含 `type` 和 `id`，同一容器内的 `id` 必须唯一，并在视图更新时保持稳定。

| `type` | 属性 |
| --- | --- |
| `column`、`row`、`wrap` | `children` 控件列表。可选 `padding`、`gap`，单位为 dp。`row` 的子项可用 `fill=true` 分配剩余宽度。 |
| `text` | `text` 内容。可选 `size`、`width`、`lines`、`emphasis`、`muted`、`padding`。 |
| `button` | `text`、`action`。可用 `style=chip` 显示选项按钮，并通过 `selected` 高亮。`enabled` 默认开启。点击时 `value` 为 0。 |
| `slider` | `text`、`action`、整数 `value`。可选 `min`、`max`（默认 0 和 100）、`unit`、显示数值的 `valueWidth` 与 `enabled`。`continuous=true` 会在拖动中发送整数值，默认在提交时发送。 |
| `progress` | `value` 为 0 到 1 的数值。 |
| `divider` | 玻璃菜单分隔线。 |

例如，返回一行可单击的操作。

```java
return List.of(Map.of(
    "type", "button", "id", "mark", "text", "标记当前曲目", "action", "mark"
));
```

宿主忽略未知控件。主题、文本、滚动、滑块动画与「减少动态效果」由宿主管理。提供方自行校验 `action`、`value` 和曲目身份，并在触发清理等操作前处理确认。

## 频谱扩展 v1

使用 `StandardMBean` 注册 `io.github.gaboron.amllspw:type=SpectrumSource,version=1,provider=<插件 ID>`，提供以下方法。

```java
Object[] spectrum(String path, long positionMs);
```

返回 `[采样率 Integer, 低频 float[], 细节 float[]]`。低频和细节数组为从直流到奈奎斯特频率的等距 FFT 幅度，细节数组可为 `null`。输入为宿主本地曲目路径与毫秒采样位置。
