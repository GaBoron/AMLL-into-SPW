# 歌词与界面说明

本文补充 [README](../README.md) 中的功能概览，记录 AMLL into SPW 的歌词显示、交互、设置及数据来源行为。

## 动态歌词与排版

- **高亮**：逐字歌词支持渐变高亮、浮动和长音发光；只有行级时间轴时使用整行高亮，不编造逐字时间。
- **多声部**：演唱者分列左右，对侧留出间距；允许多个声部同时高亮。背景人声随所属歌词组进入时展开，保留完整尾音，未展开时不预留空行。
- **滚动**：支持弹簧滚动、错落位移、活动行缩放、非活动行模糊和视口边缘淡出。连续密集换行时缩短过渡并平滑跟随；近同时声部和偶发短间隔仍保留普通弹簧，只有持续明显落后时才平滑追赶。
- **换行**：长句参考标点、空格及词界均衡折行，保留歌词文件已有的换行。
- **间奏与背景**：歌词区域透明衔接 SPW 整页背景；前奏和长间奏使用独立占位显示三点提示。

## 翻译、音译与注音

支持翻译、音译和 Ruby 注音。TTML 包含独立时间戳的逐字音译时，会将音译标在对应原文上方，随原词浮动并渐变高亮。

### 自动生成逐字罗马注音（实验性）

此选项默认关闭，仅处理识别为日语的歌词，按以下情况处理：

1. **已有逐字音译或 Ruby 注音**：直接保留，不覆盖。
2. **只有整行音译**：利用本地分词及读音匹配逐字位置，保留原有拼写。
3. **没有音译**：通过随包提供的 Kuromoji 词典离线生成读音。

汉字词组可按整词注音；只能部分匹配时，对齐可靠片段，其余音译均匀分布在对应原文上方，随原词浮动与高亮。整行无法匹配时，仍在原文上方保留整行音译。人名、特殊读法和变读可能无法准确识别。

分析在后台加载歌词时进行，并使用内存缓存；不修改歌词原文、高亮时间轴或磁盘文件。此功能适用于不同歌词来源，**不依赖 SPW Lyrics**。关闭实验性生成后恢复原有歌词；原本存在的逐字音译与注音仍受“显示音译与注音”选项控制。

## 字体、外观与动效设置

- 内置思源黑体 SC 可变字体；支持 ExtraLight、Light、Regular、Medium、Bold 和 Heavy 六种字重。默认字重为 500，最高为 900；缺字时回退系统字体。
- 字号可自动适应窗口，也可从 18–72 的预设值中选择；翻译、音译及注音按比例缩放。
- 可分别设置模糊、缩放、发光、弹簧动画、隐藏已唱歌词与音译。
- “彩色歌词”默认关闭。启用后使用封面明亮主色绘制歌词、翻译与间奏提示；没有封面时使用白色。
- 启用“隐藏已唱歌词”后，整组声部唱完才渐隐；暂停或手动浏览时重新显示。
- “减少动态效果”模式仍保持准确高亮，但关闭模糊、发光、缩放和弹簧动画。

## 交互与内容展示

### 手动浏览

鼠标悬停时显示歌词行框，点击歌词可跳转并平滑滚动。支持滚轮、方向键及 Page Up / Page Down 浏览；停止操作约三秒后恢复自动跟随。双击、Home 或 Esc 可立即恢复跟随。

### 底部信息栏

歌词末尾有独立的信息栏，展示歌词文件中的歌曲元数据与实际歌词来源。信息随歌词以较小、较淡的字样滚动，唱完后聚焦显示，也可手动滚动查看完整内容。

第三方插件可通过 [底部信息栏接口](底部信息栏接口.md) 提交名称和 key/value 信息。AMLL 自身信息在前，第三方信息按声明名称的拼音或字母顺序排列，每组末尾以更小、更淡的 `From: 名称` 标注来源；调用方无需自行实现样式。

### 纯音乐模式

纯音乐页面顶部显示“纯音乐 / INSTRUMENTAL”，中央随机展示一首完整诗词，采用独立阅读排版。选篇来自离线内置的 [chinese-poetry](https://github.com/chinese-poetry/chinese-poetry)，覆盖《诗经》《楚辞》、汉魏诗、唐诗、五代词、宋词、元曲及清词。

同一首歌保留所选诗词；切换诗词或恢复歌词时采用淡入淡出，长篇可滚动阅读。纯音乐时隐藏 AMLL 自身的歌曲元数据与歌词来源信息栏，但继续显示其他插件提交的信息。

## 歌词来源与回退

读取优先级如下：

1. 歌曲同名 `.ttml` 文件。
2. 音频标签中的原始 TTML；普通歌词标签不会阻挡其他 TTML 标签。
3. 歌曲同名 `.lrc` 文件中包含的 TTML 内容。
4. 其他插件通过原始 TTML 接口提交的歌词。
5. SPW 已解析的 SPL / LRC 时间轴。

原始 TTML 直接解析，保留原文，不经过 SPL。没有 TTML 时，插件根据宿主提供的歌词行、逐字单元和翻译，在内存中生成兼容 TTML；不改写音频、歌词文件或其他插件缓存，不为行级歌词虚构逐字时间戳。

[SPW Lyrics](https://github.com/GaBoron/SPW-Lyrics) 已支持通过接口提交完整原始 TTML。其他开发者可参考 [TTML 接入指南](TTML互通.md)；不需要提供歌词，只想补充额外元数据时可使用 [底部信息栏接口](底部信息栏接口.md)。
