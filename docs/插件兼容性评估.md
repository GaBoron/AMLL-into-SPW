# 插件兼容性评估

本文介绍 **启用 AMLL into SPW 后，其他插件的功能是否仍能生效，以及哪些功能不会作用于 AMLL 歌词**。

适用版本：AMLL into SPW 0.3.0、Salt Player for Windows 1.19.0。比较对象为 2026-10-19 时 GitHub [salt-player-plugins Topic](https://github.com/topics/salt-player-plugins) 中的其他 21 个项目。

**“可以同时启用”和“功能会作用于 AMLL”是两回事。** 文中的“已实测”表示已有实际共用结果；“预期”或“待验证”表示根据公开功能说明及源码作出的判断，不代表已完成组合测试。

## 歌词获取与处理

| 插件 | 启用 AMLL 后的表现 | 状态 |
| --- | --- | --- |
| [SPW Lyrics](https://github.com/GaBoron/SPW-Lyrics) | 自动搜索、选择和缓存歌词可继续使用；通过已实现的接口向 AMLL 提供原始 TTML，并继续向 SPW 输出普通歌词。AMLL 本地 TTML 仍享有更高优先级。 | **已实测共存，已实现 TTML 互通** |
| [spw-bilingual-lyrics](https://github.com/asukua/spw-bilingual-lyrics) | **不能调整 AMLL 原始 TTML 的双语顺序。** 该插件处理的是宿主加载前的普通歌词；当 AMLL 回退使用宿主歌词时，调整才可能体现。若同时启用其他歌词来源插件，结果还受宿主选择歌词来源的顺序影响。 | **TTML 路径不生效；回退路径待验证** |
| [salt-lyric-compat](https://github.com/sh1robana/salt-lyric-compat) | 对部分 FLAC 内嵌歌词的时间戳修正不会改变 AMLL 独立解析的 TTML；当修正后的歌词被 SPW 加载、且 AMLL 使用宿主回退时，才可能反映在 AMLL 中。 | **仅宿主回退可能生效；待验证** |
| [spw-netease-plugin](https://github.com/FUFUTPR/spw-netease-plugin) | 网易云在线播放、歌曲与封面功能不因 AMLL 接管歌词区域而失效。它通过宿主歌词回调提供的 LRC 可供 AMLL 在没有原始 TTML 时回退使用，但不能直接向 AMLL 的原始 TTML 通道提供完整歌词。与其他歌词提供插件并用时可能发生来源竞争。 | **部分功能预期生效；歌词组合待验证** |
| [SPW-Tag-Workbench](https://github.com/univers629/SPW-Tag-Workbench) | 标签、封面、歌词搜索和编辑工作台不依赖 AMLL 的歌词界面。保存到音乐文件的歌词能否在 AMLL 中体现，取决于写入格式及 AMLL 当前选择的歌词来源；普通歌词修改不能覆盖更高优先级的原始 TTML。 | **工作台预期可用；歌词结果视来源而定** |

## 歌词显示与原生界面

| 插件 | 启用 AMLL 后的表现 | 状态 |
| --- | --- | --- |
| [SPW-island（灵动词岛）](https://github.com/GaBoron/SPW-island) | 可以与 AMLL、SPW Lyrics 同时使用，桌面词岛正常显示 **SPW 已加载的歌词**。**词岛不读取 AMLL 独立获得的 TTML**；同一首歌在两个界面的歌词内容或表现可能不同。 | **已实测共存；TTML 不共享** |
| [CDL-SPW](https://github.com/H-2OS/CDL-SPW) | 独立桌面歌词窗口预期可以与 AMLL 原生歌词页并存；其显示来源为 SPW 已加载的歌词，不会自动使用 AMLL 的私有 TTML。还需确认该插件当前版本在 SPW 1.19.0 下可用。 | **预期共存；未联合验证** |
| [SPW-LyricsIsland](https://github.com/stinaCN/SPW-LyricsIsland) | 独立的桌面灵动岛和播放控制预期可继续使用；它读取宿主歌词，不会自动获得 AMLL 独立解析的 TTML。 | **预期共存；未联合验证** |
| [spw-folia](https://github.com/azkbzxf/spw-folia) | 从迷你播放器菜单打开独立 Folia 全屏歌词界面，和 AMLL 的原生歌词区域不是同一个界面位置。Folia 使用 SPW 提供的歌词数据，不会自动取得 AMLL 的私有 TTML。 | **预期共存；未联合验证** |
| [SPW-Animated-Album-Art](https://github.com/Jacob7179/SPW-Animated-Album-Art) | 动态封面修改的是原生播放页的封面组件，AMLL 修改的是歌词组件；目前检视的代码中两者并非同一 Hook 目标。不过两者都改动宿主界面，不能仅据此保证组合运行无问题。 | **预期可共存；需实测界面 Hook** |

## 播放控制、状态与其他功能

以下插件不直接修改 AMLL 的 TTML 解析或原生歌词绘制。**“预期可用”仅表示 AMLL 本身没有明显阻断其核心功能的机制**，不代表已经验证该插件单独兼容 SPW 1.19.0。

| 插件 | 启用 AMLL 后的表现 | 状态 |
| --- | --- | --- |
| [SaltSteamPlugin](https://github.com/GaodaGG/SaltSteamPlugin) | Steam Rich Presence 预期可用；其中主/副歌词字段来自宿主数据，不保证包含 AMLL 独立取得的 TTML 内容。 | 预期可用；歌词信息有限制 |
| [SaltDiscordPlugin](https://github.com/GaodaGG/SaltDiscordPlugin) | Discord Rich Presence 与封面获取预期不受 AMLL 歌词区域替换影响。 | 预期可用 |
| [salt-remote-plugin](https://github.com/motian16/salt-remote-plugin) | 远程播放控制及状态同步预期可用；其远端歌词能力仍受 SPW 提供的数据接口限制，不能直接传输 AMLL 原始 TTML。 | 预期可用；歌词信息有限制 |
| [salt-player-listen-stats](https://github.com/zhaozian81/salt-player-listen-stats) | 听歌次数、时长统计不依赖 AMLL 歌词界面。 | 预期可用 |
| [LastFmForSaltPlayer](https://github.com/akikiri/LastFmForSaltPlayer) | Last.fm Scrobble 依赖播放状态与曲库数据，不依赖 AMLL 歌词显示。 | 预期可用 |
| [spw-ai-playlist](https://github.com/AugustuXue/spw-ai-playlist) | 自然语言搜索与队列替换预期继续工作；插件依赖宿主内部反射，需确认在相同 SPW 版本下正常加载。 | 预期可用；宿主版本需验证 |
| [spw-mini-player](https://github.com/dxzywy/spw-mini-player) | 独立贴边播放窗口及播放控制预期不受 AMLL 影响；部分功能依赖 SPW 1.18.5 的宿主实现，需确认在 1.19.0 下是否正常。 | 预期可用；宿主版本需验证 |
| [spw-fixed-shuffle-plugin](https://github.com/AugustuXue/spw-fixed-shuffle-plugin) | 固定随机队列功能不修改歌词渲染；AMLL 随 SPW 当前曲目更新歌词。该插件也依赖宿主内部实现。 | 预期可用；宿主版本需验证 |
| [spw-replay-gain-calculator](https://github.com/AlierKitten/spw-replay-gain-calculator) | ReplayGain 测量和标签写入与 AMLL 歌词显示相互独立。 | 预期可用 |
| [Minokori.Plugin.NcmConverter](https://github.com/Minokori/Minokori.Plugin.NcmConverter) | NCM 转 MP3 与 AMLL 歌词界面没有直接交互。 | 预期可用 |
| [SPW-playlistimport](https://github.com/aikavvak12una/SPW-playlistimport) | 导入歌单并创建 SPW 歌单，不依赖 AMLL 歌词显示。 | 预期可用 |

若遇到具体异常，请在 [Issues](https://github.com/GaBoron/AMLL-into-SPW/issues) 中提供 SPW 版本、相关插件版本，以及失效的是哪一项功能。
